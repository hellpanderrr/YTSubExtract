YTSubExtract is a lightweight tool for extracting subtitles from YouTube videos. No accounts, no subscriptions, no ads.

Features:

🔹 Multiple extraction methods with automatic fallback
🔹 Export formats: SRT, VTT, TXT
🔹 Built-in translation via Google's `tlang` parameter
🔹 Clean TXT output (no timestamps) for AI prompts
🔹 Download entire playlists as ZIP files
🔹 Select specific videos from playlists
🔹 Real-time download progress
🔹 No tracking, no data collection, no telemetry
🔹 Persists translation settings across sessions

Technical Details:

✅ Manifest V3 compatible
✅ Open source
✅ No ads or premium features
✅ Minimal browser performance impact

Usage:

1️⃣ Open any YouTube video or playlist
2️⃣ Click the YTSubExtract icon
3️⃣ Select format and language
4️⃣ For playlists: select videos to include
5️⃣ Click the download button

Requirements:
- YouTube account login required for proper functioning (without login some videos may not work)
